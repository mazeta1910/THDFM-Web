Excluir inscrição?

Recusar todos os pendentes?

Isso move {{ liberacao_pendente|length }} inscrição(ões) para Liberação recusada (não apaga). Liberados ficam intactos. Use o × vermelho só se quiser excluir de vez.

Zerar resultados?

Liberar {{ proxima_fase.label if proxima_fase else 'próxima fase' }}?

Isso fecha {{ fases|selectattr('ativa')|map(attribute='label')|first|default('a fase atual') }}:

  • Confirma todos os placares oficiais já preenchidos
  • Placares da fase fechada ficam somente leitura
  • Libera {{ proxima_fase.label if proxima_fase else 'a próxima' }} (Ida e Volta) no bolão

Você ainda pode montar os confrontos na Árvore depois.

Fechar rodada agora?

Isso NÃO é só um salvamento. Ao confirmar:

  • A tabela Ao vivo vira histórico (ex.: Rodada 1)
  • A coluna Rodada zera para todo mundo
  • O movimento ▲/▼ passa a contar a partir deste fechamento

Só faça isso quando for divulgar o ranking da rodada. Se for engano, dá para desfazer depois.

Mudar janela de palpites?

Você vai mudar a janela para —.

  • Ida — só o jogo 1 pode ser editado
  • Volta — ida congela; libera o jogo 2
  • Fechado — ninguém edita mais palpites

Isso vale na hora para todos os participantes.

Mudar fase liberada?

Você vai liberar até —.

  • Fases acima desta ficam bloqueadas (palpites e resultados)
  • Fases até esta ficam disponíveis

Só avance a fase quando a Copa realmente chegar lá — liberar cedo demais abre placares/palpites antes da hora.

  • A coluna Rodada/movimento volta ao estado anterior
